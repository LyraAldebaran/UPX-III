# SOLARE
Solare é uma plataforma que tem como objetivo conectar produtores, investidores e consumidores de energia solar em um único lugar, reduzindo contas de luz para consumidores e trazendo oportunidades de retorno monetário para aqueles que produzem ou investem em energia solar.

## Features
- Cadastro de Consórcios/Cooperativas de consumo de créditos de energia solar para consumidores e produtores
- Dashboard de geração de créditos para produtores
- Dashboard de economia de energia para consumidores
- Gerenciamento de investimentos em fazendas de energia solar

## Stack
Frontend: HTML, CSS, Javascript e Bootstrap(?)

Backend: Spring Boot(Java)

Database: SQL Server
