## Publicação no GitHub Pages

1. Copie os arquivos desta pasta para o repositório.
2. Em **Settings > Pages**, selecione publicação a partir da branch `main` e pasta raiz `/`.
3. Aguarde o GitHub Pages gerar o endereço público.

## Arquivos principais

- `index.html`: estrutura da página.
- `style.css`: layout e identidade visual.
- `script.js`: navegação, demonstração, modal e QR Code.
- `assets/imagens/`: protótipo e logotipos.
- `assets/docs/`: documentação e PDF do protótipo.
